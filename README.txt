PRO GAMER SPEED — SITE VITRINE

CONTENU
- index.html : accueil
- reservation.html : formulaire de réservation WhatsApp
- competition.html : inscription et ticket de démonstration
- style.css : design responsive
- script.js : interactions et configuration
- assets/affiche-pro-gamer-speed.jpg : affiche fournie

OUVRIR LE SITE
1. Décompresser le dossier.
2. Ouvrir index.html dans un navigateur ou ouvrir le dossier dans VS Code.
3. Pour un test complet, utiliser l'extension Live Server de VS Code.

CONFIGURATION WHATSAPP
Dans script.js, la ligne whatsappNumber contient actuellement 2250768901166.
Le numéro est au format international, sans + ni espace.

IMPORTANT — INSCRIPTIONS AUX COMPÉTITIONS
La génération actuelle du ticket et le stockage local sont une démonstration côté navigateur.
Les données restent sur l'appareil utilisé et ne sont PAS envoyées à l'administration.
L'envoi d'e-mail, l'enregistrement centralisé, la validation du ticket et le contrôle du QR code
nécessitent un backend sécurisé (par exemple Firebase ou Supabase) et la configuration de
l'adresse e-mail de réception. Ne pas utiliser cette version de démonstration comme registre
officiel des participants.

LOCALISATION
Le site affiche Carrefour Super Sonia, Yopougon comme repère indicatif. Il ne prétend pas que
PRO GAMER SPEED possède déjà une fiche Google Maps.
